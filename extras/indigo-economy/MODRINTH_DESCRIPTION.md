# Indigo Economy

**Indigo Credits: the money on the Indigo server.** This is the wallet mod that ships inside the [Indigo client pack](https://modrinth.com/modpack/indigomc) from pack 0.4.0. It is built for one server, play.indigomc.online, and does nothing useful anywhere else.

- Minecraft: Java Edition **1.21.1**, NeoForge **21.1.248**
- Needed on both the client and the server
- Optional integration with Lightman's Currency (shops priced in Indigo Credits)

## What it does

- **One balance per player**, kept on the server and keyed to your Minecraft account. No coins to carry, lose or drop.
- **A wallet** on **Y** (or `/wallet`): balance, recent activity, and sending money to another player with a confirm step. Transfers are free and work while the other player is offline.
- **Shops** from Lightman's Currency are priced in Indigo Credits. Buying pays from your wallet and the shop owner is paid into theirs, even when they are away.
- **Discord link**: get a code in the wallet, run `/link CODE` in the Indigo Discord, and your balance, transactions and payments work there too. Same money, never a second balance.

## Install

You do not install this on its own. Install the **Indigo** pack and it is included. Guide: <https://www.indigomc.online/setup/>. Player documentation: <https://wiki.indigomc.online/mods/indigo-credits/>.
